# Dnyanesh Patil — Portfolio

A responsive, dark-futuristic developer portfolio built with plain HTML, CSS, and JavaScript.

## Included
- About, skills, selected projects, and contact sections
- No profile photo
- Responsive mobile navigation
- Scroll reveal animations and reduced-motion support
- GitHub and LinkedIn links

## Featured projects
1. Library Management System App
2. Py Bank (repository: `Banking-App`)
3. AccessGuard (repository: `Accessguard_Req_Doc`)

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a new GitHub repository and upload the contents of this folder.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Keep the framework preset as **Other**.
4. Leave the build command empty and the output directory as `.`.
5. Deploy.

## Personalize before publishing
Review the About and Skills text to ensure it accurately reflects your current experience. Add any verified technology details or project screenshots you want recruiters to see.
